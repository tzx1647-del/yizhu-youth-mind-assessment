# 《青少年心智应用测评》正式线上服务接口契约 v0.1

状态：设计与数据库结构已入开发分支；**尚未部署API / 数据库**，禁止提交真实未成年人信息。

## 已确认的产品流程
意竹先联系感兴趣的家长 → 受控记录孩子年龄、适用的监护人确认与证据 → 为对应孩子发放一次性受限链接 → 孩子填写姓名并完成A卷28情境 → 服务端独立计分并存档 → 学生直接见六步成长结果 → 意竹后台查看完整答卷与年龄、审核家长报告 → PDF发给家长，由意竹沟通。

- **学生端不出现年龄、学校、家长联系方式输入框；年龄由意竹在邀请阶段录入，仅后台可见。**
- 学生只需确认姓名；不向学生显示年龄、原始计分键、验证节点、后台异常字段。
- 家长不需要账户；没有家长登录页面。
- 当前只开放正式A卷；保留其他卷及评分版本的扩展。
- 分享真实案例须遵守独立授权规则，**测评同意不等于案例公开许可**。

## 后端鉴权边界
- 管理端使用Supabase Auth认证；服务端还必须验证 `app_admins` 管理员授权。
- 家长确认在邀请阶段按适用法律及合适的核验方式记录；只有 `consent_status=confirmed` 且证据完整，才可将邀请标记为可用。
- 学生链接为随机高熵令牌，数据库只保存SHA-256摘要；需有过期时间、使用约束和撤销途径。
- 浏览器不得取得Supabase `service_role` 密钥，也不得直接查询 `invitation_records` 或 `assessment_submissions`。
- 正式计分由服务端通过**经过核验的正式版本配置**执行，绝不能信任客户端自行上报的分数和等级。
- 无法访问服务端时不应假装“提交成功”；仅测试环境可以使用模拟数据。
- 当前A卷 v0.3.2b 与正式工作簿的永久题目ID/Q号/35节点映射已经存在，不重新建立映射源。

## 接口定义（尚未实现）
### POST /api/v1/admin/invitations
管理员登录且具备角色授权，传 `student_age` (10-20)、授权状态与授权证据引用等，不必填写学校。
服务端生成 `invitation_id`、`invitation_code`、高熵随机链接令牌，仅返回**一次**明文令牌；数据库只保留摘要。联系信息按最小化要求独立控制。
未完成适用授权时允许保存 `draft`，不得生成可提交真实答卷的有效链接。

### GET /api/v1/admin/invitations
只有意竹管理员可获取包含年龄、授权状态、测评状态、报告审核状态的列表；匿名必须401/403。

### GET /api/v1/assessment/invite?token=...
学生凭令牌进入，只返回测评状态和可作答信息；**不返回年龄、家长联系方式及未公开管理字段**。
有有效授权、未过期、未撤销且版本可用才允许作答。

### POST /api/v1/assessment/submit
请求：`{token, student_name, form_code, form_version, answers}`，按正式35节点契约验证。
流程：检查令牌/授权/版本 → 独立计分 → 事务保存答卷+提交状态 → 返回学生六步成长结果。
姓名存储与答卷按邀请ID受控关联；不得将姓名写入URL或公共日志。

### GET /api/v1/admin/submissions/:id
意竹后台可查看学生姓名、家长录入的年龄、完整答卷、34计分节点＋1验证节点、四层证据及审核状态。

### POST /api/v1/admin/submissions/:id/reports / approve / export-pdf
草稿→人工审核→批准→PDF导出。未审核不可导出正式家长版；不能自动代替意竹向家长推销。
仅使用报告正式文案，01/06冻结、其他未核准文案不得虚称已定稿。

## 真实数据上线门槛
确定中国大陆未成年人数据处理的合法依据、年龄/监护人核验、数据存储及跨境路径、隐私告知、保留/删除规则；完成HTTPS、权限、令牌重放、防刷、备份恢复和异地端到端模拟数据测试之后，方可考虑开放真实学生入口。
