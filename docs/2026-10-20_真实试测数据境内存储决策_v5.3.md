# 《青少年心智应用测评》真实试测数据存储决策 v5.3
日期：2026-10-20。接续v5.2、基线索引v2.4。

## 用户方向
第一批真实学生数据优先存储在中国大陆，目标是在符合要求的前提下降低跨境复杂性；**尚未选定托管平台、未启动迁移**。保留新加坡 Supabase Dev 作为纯虚构DEMO开发和核验环境，不收中国大陆真实未成年人数据。

## 本次核查边界
Supabase 官方托管区域未列中国大陆；迁移不是直接修改项目地区。官方Docker自托管虽可能，但带来持续服务器运维、身份认证、函数兼容与密钥管理开销，因此尚不推荐直接自托管全部Supabase。境内提供网站服务通常涉及ICP备案；选用国内托管产品时需要确认域名、备案主体和必要资质。数据存大陆不必然阻断个人信息出境：如果意竹从泰国远程访问可识别答卷、下载家长PDF，必须把跨境访问路径纳入合规评估。

## 最小实施路线（待确认）
1. 核对运营主体及备案条件、谁在什么国家读取个人信息。
2. 对比中国境内托管后端：能支持现有邀请一次性提交、A卷服务端评分、学生六步结果、管理员审核及PDF，尽量避免重写前端和报告。
3. 正式环境与虚构DEMO隔离；采用编码、尽量不收真实姓名学校电话，保留必要的监护同意记录及权限/删除能力。
4. 在合规与安全条件核实后迁移并做一次完整DEMO验收，再邀请第一批3–5名真实学生。

## 本阶段不得宣称
“数据存大陆就完全没有跨境问题”“已经完成平台迁移”“已经满足全部未成年人个人信息法律要求”。正式A卷、计分与家长报告既有冻结规则不改。
