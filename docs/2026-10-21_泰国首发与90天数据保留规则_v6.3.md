# 青少年心智应用测评｜泰国首发与数据保留规则 v6.3
日期 2026-10-21。继承 v6.2。用户同意优先泰国首发、后续扩展其他海外国家，长期运营而非人数受限的临时系统。

## 用户新决策与执行口径
家长报告**实际交付之日**起个人测评数据保留90天（用确定的天数代替不明确的自然月）；到期原则上自动删除。意竹后台拥有随时发起提前删除的权限，并设置确认步骤防止误删。学生或家长提出删除时先依法核实申请资格、处理适用例外；法律要求另行保存的必要记录采用最小化和独立保留。历史家长PDF已交给他人者，不保证能远程删除其副本，应在说明中告知。

## 技术实施前置问题
现有 invitation_records、assessment_submissions、parent_report_reviews 已有关联。需定义“报告已交付”时间戳（当前表只发现 approved_at，没有交付时间，不能误把审核批准时间当交付时间）、确定删除依赖顺序或约束、安全授权、审计最小记录、按期自动清理机制。当前**尚未编码、部署或实际执行删除**，不能声称功能完成。

## 重要边界
泰国适用的PDPA及未成年人同意、告知、数据跨境规则需根据实际处理身份继续核定。保留与删除不修改已冻结A卷、评分、学生六步与家长六章内容。现有新加坡Supabase Dev仍为虚构DEMO，不直接录入真实学生。
